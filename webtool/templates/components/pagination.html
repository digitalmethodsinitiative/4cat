{# The pagination bar, for every paged listing there is. Which pages to offer, where the gaps between them are and which one is current is the same wherever pages are listed; what a page *link* is, is not. On the dataset overview it is a plain href, in the Explorer it swaps the item list in place. So this decides the pages, and the caller renders the links: {% from "components/pagination.html" import page_links %} {% call(number, label) page_links(page, pages) %} {{ label }} {% endcall %} The caller is handed the page number and the text to put in the link - the number itself, or 'Previous'/'Next' for the step links, which are only shown when `steps` is set. Nothing at all is rendered when there is one page, so a listing that fits on one does not have to ask before including this. Styled by components/pagination.css, which is what keeps the bar the same thing to click wherever it turns up. Params: page the page being shown, 1-indexed pages how many there are label what the bar is called, for screen readers classes class on the
; add 'above' for the copy over a list steps whether to offer previous/next either side of the numbers #} {% macro page_links(page, pages, label="Pages", classes="pagination", steps=False) %} {% if pages > 1 %} {# the first and last page, and two either side of where we are #} {% set numbers = [1, pages] %} {% for offset in [-2, -1, 0, 1, 2] %} {% if 1 <= (page + offset) <= pages and (page + offset) not in numbers %} {% set _ = numbers.append(page + offset) %} {% endif %} {% endfor %}
    {% if steps and page > 1 %}
  1. {{ caller(page - 1, "« Previous") }}
    2. {% endif %} {% set previous = namespace(number=0) %} {% for number in numbers|sort %} {% if number > previous.number + 1 %}
  2. …
    3. {% endif %}
  3. {% if number == page %} {{ number }} {% else %} {{ caller(number, number) }} {% endif %}
    4. {% set previous.number = number %} {% endfor %} {% if steps and page < pages %}
  4. {{ caller(page + 1, "Next »") }}
    5. {% endif %}
{% endif %} {% endmacro %}
