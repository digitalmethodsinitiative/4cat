{# Watches for annotations a processor is making. Processors write annotations to the dataset they were run on, in the background, so nothing tells this page when new ones appear. This element goes and asks - but only while there is something that could be writing them, since that is the only time the answer can change on its own. The reply renders this element again: while an analysis is still running it comes back polling, and once none is it comes back listening for the next one to be queued. Nothing here is visible; it is a question, not a control. `running` and `state` are what the page currently has. The server compares them with what is true now, and announces an update only when whatever could have been writing has stopped *and* the annotations are no longer the ones this page was rendered with. So a processor that annotated nothing never disturbs anyone's reading, and one that is still going does not either - a long analysis writing its annotations in batches is left to finish first.
