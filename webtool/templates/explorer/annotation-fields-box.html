The editor beneath is fetched by htmx on the first click - one click both opens the row and loads it, so a dataset page nobody annotates never pays for it. A dataset with no fields yet has nothing to show while the editor is closed, so the right-hand cell stays out of the way until there is either a field or an open editor. Whether there are any is told to this box rather than read off the page: the badges are swapped in out of band, both when fields are saved and when a processor turns out to have made some, and a count read out of the DOM would not be something Alpine re-reads when that happens. The marker that watches for processor-made fields says so as it arrives. Always present once the dataset is finished, whichever pane is showing: the fields describe the dataset, not the Explorer. Expects: dataset, annotation_fields, can_annotate, annotation_watch #}
